# ATPL(A) — cours disponibles

**7 chapitres, 105 questions**, en français et en anglais, avec SVG et variantes d’unités.

105 QCM à quatre choix sont marqués pour le format examen ; 0 questions sont réservées à la révision. Chaque chapitre comporte 15 questions.

La couverture reste partielle : présence d’une matière ne signifie pas que tous ses objectifs EASA sont couverts. Les quiz de chapitre ne constituent pas des épreuves complètes. Validation instructeur à obtenir.

## Régénération

```text
python scripts/seed/atpl_content.py
python scripts/illustrations/atpl_illustrations.py
node scripts/illustrations/ppl_unit_variants.mjs
```

Les chapitres sont rangés par matière dans `content/fr/atpl` et leurs auteurs dans `scripts/seed/atpl`. Import transactionnel : `scripts/seed/atpl_content.sql`. Le changement d’unités ou de langue ne modifie pas le cadre France / EASA.
