# IR(A) — cours disponibles

**8 chapitres, 120 questions**, en français et en anglais, avec SVG et variantes d’unités.

120 QCM à quatre choix sont marqués pour le format examen ; 0 questions sont réservées à la révision. Chaque chapitre comporte 15 questions.

La couverture reste partielle : présence d’une matière ne signifie pas que tous ses objectifs EASA sont couverts. Les quiz de chapitre ne constituent pas des épreuves complètes. Validation instructeur à obtenir.

## Régénération

```text
python scripts/seed/ir_content.py
python scripts/illustrations/ir_illustrations.py
node scripts/illustrations/ppl_unit_variants.mjs
```

Les chapitres sont rangés par matière dans `content/fr/ir` et leurs auteurs dans `scripts/seed/ir`. Import transactionnel : `scripts/seed/ir_content.sql`. Le changement d’unités ou de langue ne modifie pas le cadre France / EASA.
